## LONGSHOT — Ballistic Overwatch

A semi-realistic first-person sniper game rendered on a single canvas. Read the wind, dope bullet drop, hold your breath, and work through ten operations that escalate in range, weather, and target behaviour. Spend mission credits in the armory on four rifle platforms, five ammunition loads, per-rifle upgrades, and a ballistic computer.

### Controls

| Action | Keyboard / mouse | Gamepad |
| --- | --- | --- |
| Aim | Mouse / arrows / WASD | Left + right sticks |
| Fire | Left mouse / Space | RT |
| Scope | Right mouse / Z | LT, X toggles |
| Hold breath | Shift | LB |
| Rangefinder | F | RB |
| Ballistic solution | T | Y |
| Reload | R | A |
| Change zero | [ / ] | D-pad up/down |
| Cycle owned ammo | 1–5 | B |
| Pause | P / Escape | Start |

Open `index.html` through any static server (or run `./start.sh` with the provided runtime) to play. Progress, credits, rifles, and upgrades are saved to `localStorage`.
